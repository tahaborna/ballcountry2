## ۱) پیش‌نیازهای حساب و فایل

- [ ] **حساب Play Console** — ثبت‌نام یک‌بارِ ۲۵ دلار (https://play.google.com/console)
  - اگر حساب **شخصیِ جدید** است: پیش از انتشار عمومی، گوگل الزام می‌کند اپ را در **تست بسته** با **حداقل ۱۲ آزمون‌گر opt-in شده به مدت ۱۴ روز پیوسته** اجرا کنی (الزام قبلیِ ۲۰تایی به ۱۲ کاهش یافته). برنامه‌ریزی: از حالا ۱۲+ دوست/هم‌تیمی آماده کن (گروه تلگرام عالی است).
- [ ] **فایل AAB** ساخته شود: `build-apk.bat` → گزینه release (یا `cd android && gradlew.bat bundleRelease`)
  - خروجی: `android\app\build\outputs\bundle\release\app-release.aab`
- [ ] **targetSdk = 36 (اندروید ۱۶)** — از ۳۱ اوت ۲۰۲۶ گوگل برای اپ جدید و به‌روزرسانی‌ها API 36 می‌خواهد.
  - در `android/variables.gradle` مقدار `compileSdkVersion` و `targetSdkVersion` را 36 بگذار و دوباره build بگیر.
- [ ] **keystore امن** — `keystore/ballcountries.keystore` + `keystore.properties` را فقط جایی خارج از کامپیوترت ذخیره کن (بدون این‌ها هیچ‌وقت آپدیت نمی‌توانی منتشر کنی).
- [ ] **bundle id درست:** `ir.ballcountries.game` (در `capacitor.config.json` و PWABuilder/Capacitor یکسان باشد)
- [ ] **شماره نسخه زیاد شده:** `py tools/bump-version.py` (هر انتشار)

4. **میدان نبرد تاکتیکی** (انتخاب آرایش و فرمانده)
5. **چرخه ۱۰ صندوق / صندوق فصلی** (جواهرات و جوایز)

## ۳) طبقه‌بندی سنی محتوا (IARC — Content rating)

فرم در: Play Console → Policy → **App content → Content rating**
پاسخ‌های پیشنهادی با توجه به محتوای بازی (جنگ کارتونی بدون خون، بدون ترسناک، بدون زبان رکیک، بدون قمار، بدون خرید درون‌برنامه):

- دسته: **بازی** (نه اپ)
- خشونت: خشونت **فانتزی/کارتونی خفیف** دارد (برخورد توپ‌ها، عقب‌نشینی) — خشونت واقع‌گرایانه، خون، زخم: **ندارد**
- محتوای جنسی، نگریستن برهنه، زبان توهین‌آمیز، مواد، قمار، خودکشی، نفرت‌پراکنی: **هیچ‌کدام ندارد**
- تعامل کاربران/اشتراک‌گذاری مکان/خرید: **ندارد** (چت و وب‌عمومی ندارد)
- نتیجه مورد انتظار: رده سنی **«همه» / Everyone (۳+)** — اگر گوگل نمره Teen نداد جای نگرانی نیست؛ همان را ثبت کن.

## ۴) سیاست حریم خصوصی و Data safety

### 🔗 آدرس سیاست حریم خصوصی
- فایل آماده: **`dist/privacy-policy.html`** (دو زبانه)
- آن را همراه بازی روی همان هاست (Netlify) آپلود کن و در فرم Console این آدرس را بده:
  `https://<نام-سایت>.netlify.app/privacy-policy.html`

### 📋 فرم Data safety (پاسخ‌های دقیق)
بازی به‌صورت پیش‌فرض **هیچ داده‌ای از دستگاه خارج نمی‌کند**. فقط اگر **آداپتور ابری HTTP** را فعال کرده باشی، موارد ستاره‌دار برقرار است:

| سؤال فرم | پاسخ |
|---|---|
| آیا اپ داده جمع‌آوری/اشتراک می‌کند؟ | خیر (بدون ابری) / بله فقط با انتخاب کاربر (ابری*) |
| نوع داده* | اطلاعات حساب: نام کاربری، رمز عبور (فقط هشِ SHA-256 منتقل/ذخیره می‌شود) |
| هدف* | احراز هویت حساب بازیکن برای ذخیره ابری |
| داده در انتقال رمزگذاری می‌شود؟* | بله (فقط HTTPS) |
| کاربر می‌تواند حذف کند؟* | بله (خروج از حساب + پاک‌سازی سرور) |
| تبلیغات | ندارد |
| خرید درون‌برنامه | ندارد |
| جمع‌آوری کودکان | خیر |
| اشتراک با شخص ثالث | خیر (هیچ SDK تبلیغاتی/تحلیلی نیست) |

در بخش **App content** سایر فرم‌ها:
- Ads: **بدون تبلیغ** ✅
- App access: **همه امکانات بدون ورود/کلید** (اکانت ابری اختیاری است — این را در توضیح بنویس)
- News / COVID / Government / Health / Financial: **خیر**
- Encryption (رمزنگاری اختصاصی): **خیر** (فقط HTTPS استاندارد — معاف)
