# کشورهای توپی: فرمانروایی جهان 🌍

بازی استراتژیک ـ مدیریتی موبایلی با کشورهای امروزی و تاریخی به شکل توپ‌های بامزه با پرچم واقعی.
رابط کاربری کاملاً فارسی (RTL)، نقشه جهان قابل پیمایش و ویرایش، دیپلماسی چهارسطحی، جنگ کارتونی،
سیستم ۱۰ صندوق (انتخاب ۹ صندوق)، پاداش روزانه ۳۰روزه، سطح و سکه، و ذخیره خودکار پیشرفت.

## ساختار پروژه

```
ball-countries/
├── capacitor.config.json   ← پیکربندی اندروید (Capacitor)
├── package.json
├── server/server.js        ← سرور نمونه ذخیره ابری (بدون وابستگی)
└── www/                    ← کل بازی (بدون وابستگی، آفلاین کامل به‌جز فونت اختیاری)
    ├── index.html
    ├── css/style.css
    └── js/
        ├── data.js      ← کشورها، پرچم‌ها، ساختمان‌ها، نیروها، صندوق‌ها، مأموریت‌ها (داده‌محور)
        ├── engine.js    ← اقتصاد، دیپلماسی، نبرد تاکتیکی، سطح، صندوق‌ها، ذخیره
        ├── mapview.js   ← نقشه SVG با زوم/پن + رندر پرچم و توپ‌ها + ویرایشگر
        ├── audio.js     ← جلوه‌های صوتی و موسیقی (WebAudio)
        ├── cloud.js     ← ذخیره ابری: حساب ساده + آداپتور دستگاه/HTTP
        ├── ui.js        ← همه منوها و صفحه‌ها
        └── main.js      ← راه‌اندازی و حلقه بازی
```

## ذخیره ابری (حساب کاربری ساده)

- از منوی اصلی: **☁️ حساب** — ثبت‌نام/ورود با نام کاربری و رمز (رمز به‌صورت SHA-256 هش می‌شود).
- **دو آداپتور:** «دستگاه (شبیه‌ساز ابری)» برای تست و چندحسابی روی یک گوشی، و «سرور ابری (HTTP)».
- پاکت ابری همان «کد پشتیبان» بازی است؛ پس با پشتیبان‌گیری دستی تنظیمات و انتقال با کپی/پیست کاملاً سازگار است.
- همگام‌سازی خودکار (قابل خاموش‌کردن): پس از رویدادهای مهم، هر ۳۰ ثانیه در صورت تغییر، و هنگام خروج از بازی.
- هنگام بازیابی، اگر نسخه ابری و دستگاه فرق کنند، **خلاصه هر دو** (سطح/سکه/قلمرو/زمان) نمایش داده می‌شود تا انتخاب کنی.

سرور نمونه (بدون وابستگی):

```bash
cd ball-countries/server
node server.js 8787
# در بازی: آداپتور «سرور ابری (HTTP)» و آدرس http://<IP-دستگاه-سرور>:8787 را وارد کن
```

قرارداد سرور: `POST /register|/login|/save|/load` — هر بک‌اند دیگری (PHP/Go/…) با همین چهار مسیر جایگزین می‌شود. برای استفاده عمومی، حتماً پشت HTTPS قرار دهید.

## اجرای نسخه وب (تست سریع)

هر سرور استاتکی کافی است، مثلاً:

```bash
cd ball-countries/www
python -m http.server 8080
# سپس http://localhost:8080 را در مرورگر باز کنید
```

یا: `npm install` و سپس `npm run serve`.

## نصب روی اندروید — سه راه

### راه ۱: APK با PWABuilder (بدون نصب هیچ ابزاری) ⭐ ساده‌ترین
1. بازی وب را روی یک هاست HTTPS قرار دهید (GitHub Pages، Netlify Drop یا Firebase Hosting)
   — **پوشه آماده `dist/` را بکشید و در [app.netlify.com/drop](https://app.netlify.com/drop) رها کنید**
   (راهنمای گام‌به‌گام: `dist/DEPLOY-GUIDE.md`)
2. به [PWABuilder.com](https://www.pwabuilder.com) بروید و آدرس بازی را بدهید
3. «Package for stores ▸ Android» و سپس Download — فایل `app-release-signed.apk` آماده نصب/انتشار است
4. فایل APK را به گوشی بفرستید و نصب کنید (اجازه «نصب از منابع ناشناس» را بدهید)

> آیکون‌ها و manifest و سرویس‌ورکر از قبل در `www/` آماده‌اند (`icons/icon-512.png`).

### راه ۲: APK رسمی Capacitor با یک کلیک (نیازمند Node + Android Studio)
روی ویندوز، فایل **`build-apk.bat`** را اجرا کنید — خودش همه مراحل را انجام می‌دهد و در پایان مسیر APK را نشان می‌دهد:

```
android\app\build\outputs\apk\debug\app-debug.apk
```

پیش‌نیازها: [Node.js LTS](https://nodejs.org) + [Android Studio](https://developer.android.com/studio) (JDK 17 و SDK را با هم نصب می‌کند).

### راه ۳: نصب مستقیم PWA از مرورگر گوشی (بدون APK)
1. PC و گوشی را روی یک Wi-Fi بگذارید، سپس روی PC: `cd ball-countries/www && py -m http.server 8000`
2. IP کامپیوتر را ببینید (`ipconfig`) و در کروم گوشی باز کنید: `http://<IP-کامپیوتر>:8000`
3. منوی کروم ▸ **Add to Home screen / نصب برنامه** — بازی با آیکون اختصاصی و کاملاً آفلاین نصب می‌شود

### ساخت خروجی اندروید با Capacitor (جزئیات دستی)

پیش‌نیازها: **Node.js 18+**، **JDK 17**، **Android Studio** (با Android SDK 34).

```bash
cd ball-countries
npm install                 # نصب Capacitor
npx cap add android         # ساخت پروژه اندروید (فقط بار اول)
npx cap sync android        # همگام‌سازی فایل‌های www با پروژه اندروید
npx cap open android        # باز کردن در Android Studio
```

سپس در Android Studio: **Build ▸ Build App Bundle(s) / APK(s) ▸ Build APK(s)**.
خروجی debug در `android/app/build/outputs/apk/debug/app-debug.apk` ساخته می‌شود.

ساخت خط فرمانی بدون Android Studio (بعد از نصب SDK):

```bash
cd android
gradlew.bat assembleDebug
```

### امضای release و انتشار در گوگل‌پلی (آماده شده) 🔐

امضای release به‌صورت خودکار مدیریت می‌شود:

1. **ساخت keystore (فقط یک بار):**
   ```bash
   py tools/make_keystore.py
   ```
   رمز تصادفی می‌سازد و در `keystore/keystore.properties` ذخیره می‌کند.
   ⚠️ پوشه `keystore/` هرگز commit نمی‌شود — پشتیبان امن (فلش/ایمیل شخصی) نگه دارید؛ بدون آن هرگز نمی‌توانید آپدیت منتشر کنید.

2. **اعمال امضا و نسخه‌بندی (بعد از هر `npx cap add android`):**
   ```bash
   py tools/apply_signing.py
   ```
   این اسکریپت `app/build.gradle` را به keystore وصل می‌کند و `versionCode`/`versionName` را از `android/version.properties` می‌خواند.

3. **افزایش نسخه برای هر انتشار:**
   ```bash
   py tools/bump-version.py patch   # یا minor / major
   ```

4. **ساخت خروجی‌ها:**
   ```bash
   cd android
   gradlew.bat assembleRelease   # APK امضاشده: app/build/outputs/apk/release/app-release.apk
   gradlew.bat bundleRelease     # AAB برای گوگل‌پلی: app/build/outputs/bundle/release/app-release.aab
   ```

یا همه مراحل با فایل `build-apk.bat` (انتخاب debug یا release بعد از sync).

چک‌لیست انتشار:

- [ ] `npx cap sync android` برای فایل‌های تازه `www/`

## امکانات نسخه اول

- نقشه جهان SVG با زوم/جابه‌جایی/پینچ و ۲۶ کشور امروزی + ۵ کشور تاریخی + دولت‌های آزاد
- سناریوی تاریخی جداگانه «عصر امپراتوری‌ها» (باز شدن در سطح ۵) تا مرزهای تاریخی و امروز قاطی نشوند
- ویرایشگر نقشه: جابه‌جایی توپ‌ها با کشیدن + افزودن کشور سفارشی با پرچم دلخواه
- پایتخت/شهر/قلمرو/منابع (سکه، غذا، انرژی، فلز، چوب، فناوری، نیروی انسانی)
- ۱۱ ساختمان، ۶ نوع نیرو، ۴ شاخه فناوری، مالیات و رضایت عمومی
- دیپلماسی: دوستی/بی‌طرفی/تنش/دشمنی + هدیه، تجارت، اتحاد، کمک نظامی، تحریم، خرید منطقه با مذاکره، اعلام جنگ، پیمان صلح و پیامد شکستن پیمان (اعتبار دیپلماتیک)
- جنگ کارتونی تاکتیکی نوبتی: انتخاب آرایش (تهاجمی/دفاعی/پخش)، فرمانده (۵ فرمانده با پاداش متفاوت، باز شدن با سطح) و تاکتیک هر دور (حمله همه‌جانبه، ضربه هدفمند با شکستن دیوار، دفاع تاکتیکی، عقب‌نشینی) — بدون خشونت، با حمله دریایی و پشتیبانی متحدان
- چرخه صندوق‌ها: ۱۰ صندوق، بازکردن ۹ صندوق، صندوق دهم ویژه چرخه بعد با جایزه دوبرابر + نمایش شفاف احتمال‌ها
- پاداش روزانه ۳۰روزه با بلیت جبران غیبت
- مأموریت‌های ترتیبی + ۸ دستاورد + فروشگاه ظاهر توپ
- ذخیره خودکار محلی (localStorage) + پشتیبان‌گیری/بازیابی با کد متنی (برای ذخیره ابری دستی)
- جلوه‌های صوتی و موسیقی پس‌زمینه تولیدی با WebAudio (بدون فایل صوتی خارجی) با کلید خاموش/روشن در تنظیمات
- رویداد فصلی ۱۴روزه تقویم‌محور (آفلاین): ۶ تم فصلی، مأموریت‌های محدود زمانی با امتیاز فصل، مسیر جایزه و «صندوق فصلی» با ظاهر انحصاری «پرچم فصلی»
